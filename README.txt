VEYmont — Equity Intelligence
==============================

This is the first static prototype of the VEYmont stock-research website.

FILES
- index.html  = the website
- styles.css  = the design
- script.js   = demo stock-search behavior

IMPORTANT
The stock figures in this prototype are demo/static values. They are NOT a live market-data feed.
Before using VEYmont publicly or commercially, replace demo data with a properly licensed/current data source and review the site's legal, privacy, payment, and financial-disclosure requirements.
